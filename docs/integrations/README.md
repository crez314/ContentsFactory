# 외부 연동 확인 항목

§8 과 부록 B 의 착수 전 확인 항목을 실측해 기록하는 곳이다.
플랫폼별로 `{platform}.md` 를 만든다. 아래는 그 템플릿이자 현재 상태다.

## 상태

| # | 항목 | 담당 | 상태 |
| --- | --- | --- | --- |
| 1 | 대상 SNS 플랫폼별 비공개 업로드 지원 여부 | 개발 | ☐ 미확인 |
| 2 | 플랫폼별 API 쿼터 및 계정 확보 | 운영 | ☐ 미확인 |
| 3 | 생성 모델 어댑터 후보 2종 이상 선정 및 단가 확인 | 개발 | ☐ 미확인 |
| 4 | 임베딩 API 선정 (차원·정규화·단가) | 개발 | ☐ 미확인 |
| 5 | 자산 속성 표준값 최종 확정 | 운영 | ☑ §4.1 표 그대로 마스터에 반영 |
| 6 | 아티스트 계약상 AI 2차 가공 허용 범위 | 법무 | ☐ 미확인 |
| 7 | 브랜드 가이드라인 (QC brand 룰셋) | 마케팅 | ☐ 금지어 사전만 임시 |
| 8 | 금지 주제·금칙어 목록 | 운영 | ☐ 데모용 5건만 |
| 9 | 콘텐츠 1건당 목표 원가 | 경영 | ☐ 미확인 |
| 10 | 에이전트별 초기 일일 예산 | 경영 | ☐ 데모값 |

6번이 가장 중요하다. 소속 아티스트 계약에 AI 생성물 제작·활용 조항이 없으면
자산 라이선스 필드를 채울 수 없고, Order Validator 의 라이선스 검증(5·6·7번)이 무의미해진다.

## 생성 모델 어댑터 확인 항목 (§8.1)

| Capability | 확인할 것 |
| --- | --- |
| `image` | 참조 이미지 입력 지원 여부, 인페인팅·업스케일 지원, 단가 |
| `video` | 비동기 Job 방식 여부와 폴링 주기, 3~6초 클립 지원, 단가 |
| `voice` | 한국어 품질, 길이 예측 가능 여부 |
| `music` | 상업적 이용 라이선스, 무드 지정 방식 |
| `embedding` | 벡터 차원, 정규화 여부, 단가 |

어댑터를 붙일 때 `libs/model-abstraction/src/backends/http-generic.backend.ts` 의
`buildRequest` 만 벤더 형식에 맞게 채우면 된다. 나머지 코드는 벤더 이름을 모른다.
